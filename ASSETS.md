# Происхождение изображений

Все изображения, используемые текущими страницами, находятся в `assets/` и созданы специально для этой демонстрационной витрины как исходный SVG-код с помощью AI-assisted tooling в рамках проекта Максима Асатурова. Они не скачаны из фотобанка, магазина или результатов поиска. Это условные иллюстрации, а не фотографии настоящих товаров.

| Файлы | Назначение | Происхождение |
| --- | --- | --- |
| `bouquet-p-001.svg` … `bouquet-p-009.svg` | Девять иллюстраций карточек и корзины | Оригинальные векторные композиции для этого проекта |
| `mark.svg` | Локальный цветочный знак и favicon | Оригинальная геометрическая SVG-иконка |
| `cart.svg` | Иконка кнопки корзины | Оригинальный SVG-контур; декоративный `alt=""` внутри подписанной кнопки |
| `demo-map.svg` | Декоративная схема в подвале | Оригинальная абстрактная схема; не настоящая карта или адреса |
| `docs/screenshots/*.png` | README | Реальные снимки локальной демо-версии, состоящей из перечисленных материалов |

Прежние hotlink-изображения Cvetland, Google Images и Yandex, а также внешний iframe карты удалены из рабочих страниц. Подтверждения прав на прежние фотографии не было, поэтому они не копировались в репозиторий и не используются в новых скриншотах. В текущих рабочих изображениях сторонние материалы, требующие внешней атрибуции, не используются; общая лицензия проекта этим файлом не меняется.
